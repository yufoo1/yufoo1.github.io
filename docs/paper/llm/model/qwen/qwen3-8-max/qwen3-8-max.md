# Qwen3.8-Max: A New Bar for Coding and Cowork

来源：[官方博客](https://qwen.ai/blog?id=qwen3.8)。

作者：Qwen Team（阿里巴巴）

## 架构与模型规模

Qwen3.8-Max 建立在 Qwen3.5 的混合注意力与高稀疏 MoE 架构之上，面向复杂编程与长程自主工作任务进行扩展。模型总参数量达 2.4T，每个 token 激活 95B 参数，支持 1M 上下文窗口。这也是首个开放权重的 Qwen-Max 级别模型。

## 视觉闭环与混合智能体

面向长程多模态任务，Qwen3.8-Max 将视觉感知从单纯的输入理解扩展为贯穿规划、执行、验证与迭代的原生反馈闭环。模型在执行过程中持续观察中间渲染结果与空间布局，自主定位偏差并修正方案。同时，模型采用代码编写与图形界面操作协同的 Hybrid Agent 范式，既能通过代码高效构建底层逻辑，又能直接交互验证真实运行中的应用状态。

## 真实环境强化学习扩展

为在不同智能体执行框架间一致提升长程任务能力，Qwen3.8-Max 在数千个真实环境规模上联合扩展了 RL 环境与训练算力。环境构建沿任务跨度、工作区目录复杂度与执行框架三个正交维度解耦扩展，使环境多样性呈组合式增长而无需逐任务定制接入。在此基础上，统一奖励系统在可扩展评分准则下整合执行检查、文本与视觉准则裁决及智能体检查，消除了任务专用验证器的标准差异。训练管线同时引入在线数据均衡器动态平衡每个批次在任务、难度与工作区上的分布，通过抑制批次间梯度方差保障大规模 RL 训练持续稳定收敛。
